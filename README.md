# 건강검진 수치 해석 어시스턴트

> 교육용 프로젝트입니다. 검진 수치와 사용자 정보는 모두 더미 데이터이며, 진단·약 처방을 하지 않습니다.

## 1. 무엇을 푸나
건강검진 수치를 넣으면 항목별 판정 구간(정상 / 경계 / 질환의심)과 생활습관 지침을 근거(기관명·기준일, 지침 문서)와 함께 답합니다.

## 2. 활용한 패턴 (Day 1~7)
- Day 1: 프롬프트·구조화 출력 — 판정·BMI 결과를 Pydantic 모델(`JudgeOutput`, `BmiOutput`, `QueryResponse`)로 고정하고 응답을 `answer`·`contexts`·`trace` 세 키로 맞춥니다.
- Day 2: RAG (하이브리드 검색) — 키워드 검색과 Chroma 벡터 검색(Titan 임베딩)을 합쳐 `data/guides/*.md`에서 지침을 찾고, 결과를 `contexts`(`파일명#헤더`)로 돌려줍니다. (`src/retriever.py`)
- Day 3: ReAct — `create_agent`가 질문에 따라 판정·계산·검색 도구를 골라 호출합니다.
- Day 4: 도구 다중 — 한 질문에 `judge_checkup_item`, `judge_blood_pressure`, `calc_bmi`, 지침 검색을 함께 씁니다.
- Day 5: 가드레일 — 입력 가드(진단 확정·약 요청 차단, 인젝션 제거, 개인정보(주민등록번호·전화번호·이메일) 마스킹)와 출력 가드(구간 표기 대조, 진료 안내·출처·가정 보충)를 코드로 둡니다. 인젝션은 Day 5 방식(덮어쓰는 동작과 현재 지시 대상이 함께 나올 때만 감지)으로 잡으며, 강의 실습과 과제 저장소의 Day 5 공격 세트 각 10문항과 추가 공격 유형 6가지(서버 종료 명령, 권한 상승, 역할극, 프롬프트 요약, 규칙 목록 나열, 맥락 초기화)를 모두 감지하고 정상 문장 오탐은 없습니다. Day 5 과제 제출 코드의 탐지 층(난독화 해제: 전각·제로폭 문자, 동형 문자, 띄어 쓴 글자, leetspeak, 철자 섞기, base64·hex·URL 인코딩, 코드 블록 감싸기 / 다국어·가짜 대화·페이로드 분할·거절 억제·앞 내용 반복 규칙 / 약한 신호 점수제)도 옮겨 와, 우회한 공격도 감지합니다. 자격 증명(AWS 키, JWT, API 토큰, Bearer)·카드번호·사번도 마스킹합니다. (`src/guardrails/input_guard.py`, `src/guardrails/output_guard.py`)
- Day 5: 미들웨어 — 개인정보 마스킹, 모델 호출 실패 시 고정 안내 문구로 응답하고 서버는 멈추지 않습니다.
- Day 7: Observability — 응답 `trace`에 단계별(가드, 도구 호출, 검색) 기록을 남깁니다.
- Day 7: 평가 — 질문 20건 인-아웃 세트와 `evaluation/run_eval.py`로 카테고리별·전체 통과율을 잽니다.

쓰지 않은 패턴 (이유):
- HITL: 되돌릴 수 없는 작업이 없어 쓰지 않았습니다.
- Multi-Agent Supervisor: 에이전트 하나로 충분한 규모라 쓰지 않았습니다.
- Plan-Execute·장기 메모리: 한 번 묻고 한 번 답하는 서비스라 쓰지 않았습니다.
- MCP 서버 연동(선택)도 넣지 않았습니다.

## 3. 아키텍처
```
질문 → 입력 가드(길이·형식, 개인정보 마스킹, 인젝션 제거, 약·진단 확정 차단)
     → 에이전트(모델이 항목·수치 추출 → 도구 호출)
         ├─ judge_checkup_item / judge_blood_pressure / calc_bmi (코드 판정, data/criteria.json)
         └─ 지침 검색 (키워드 + Chroma 하이브리드, data/guides/*.md)
     → 출력 가드(진단 단정·약 추천 차단, 구간 표기 대조, 질환의심 진료 안내, 출처·가정 보충)
     → 고정 면책 1문장을 코드가 붙여 {answer, contexts, trace} 응답
```

| 일 | 담당 |
|---|---|
| 구간 판정, 판정 보류 | 코드 (`judge_checkup_item`) — 모델은 숫자 비교를 틀릴 수 있기 때문 |
| 체질량지수 계산 | 코드 (`calc_bmi`) |
| 질문에서 항목·수치 읽기 | 모델(추출) + 코드(검증) |
| 지침 검색과 요약 | RAG + 모델 |
| 고정 면책 문장 | 코드 (`run_query`) |
| 개인정보 마스킹, 인젝션 제거, 약·진단 확정 요청 감지 | 코드 (입력 가드) |
| 금지 표현 차단, 구간 표기 대조, 진료 권고 보충 | 코드 (출력 가드) |

지침 검색(Chroma)만 실패하면 코드 판정 결과와 기준 출처는 그대로 보여 주고 지침 자리에 "근거 지침 없음"을 안내합니다.

## 4. 실행 방법
```bash
python -m venv .venv
.venv/Scripts/activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt      # Python 3.13 권장 (.python-version). 3.14는 RAGAS 의존성(scikit-network) 빌드가 실패합니다
cp .env.example .env              # AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION(us-east-1) 입력
uvicorn src.app:app --port 8000
```
요청 예시:
```bash
curl -X POST http://localhost:8000/query -H "Content-Type: application/json" \
  -d '{"question": "공복혈당이 108이 나왔어요"}'
```
테스트: `python -m pytest -q tests`, 평가: `python evaluation/run_eval.py --out evaluation/results/round2.json`

웹 화면 (`web/`, React + TypeScript + Vite): 위 백엔드를 8000번으로 띄운 상태에서 다른 터미널로 실행하고 http://localhost:5173 에 접속합니다. Node.js가 필요합니다.
```bash
cd web
npm install
npm run dev        # 타입 체크·빌드: npm run build
```
- 질문을 입력하면 답변(마크다운, 표 포함), 근거 지침(`contexts`), 판정·도구 호출 과정(`trace`)을 한 화면에서 펼쳐 볼 수 있습니다. 로딩·오류 상태와 예시 질문 버튼이 있습니다.
- Vite 개발 서버가 `/query` 요청을 `http://127.0.0.1:8000`으로 넘기므로(`web/vite.config.ts`의 프록시) 백엔드에 CORS 설정이 필요 없습니다.
- 추가 라이브러리는 마크다운 렌더러 `react-markdown`과 표 지원 `remark-gfm`뿐입니다.

모델은 Bedrock의 10단계 (리전, 모델 ID) 순서입니다(`src/shared/llm.py`의 모듈 상수 목록 하나이며 RAGAS 심판 `evaluation/run_ragas.py`도 같은 목록을 씁니다). 1~5차 Sonnet 4.6: us-west-2 `us.anthropic.claude-sonnet-4-6` → us-west-2 `global.anthropic.claude-sonnet-4-6` → us-east-1 `us.…` → us-east-1 `global.…` → ap-northeast-2 `global.…`. 6~10차 Sonnet 4.5: 같은 리전 순서로 `anthropic.claude-sonnet-4-5-20250929-v1:0`(`us.`/`global.`). 일일 토큰 한도(ThrottlingException)에 걸리면 서비스는 그 질문을, RAGAS는 그 회차를 다음 차수로 처음부터 다시 처리하고, 답한 모델·리전은 trace의 `llm_model` 단계와 결과 파일에 남습니다. Haiku·Nova·gpt-oss는 쓰지 않습니다. AWS 자격 증명은 `.env`에서 읽고 `AWS_DEFAULT_REGION`은 모델 순서와 무관한 기본값입니다. 임베딩은 `amazon.titan-embed-text-v2:0`입니다. 비밀 값은 `.env`에서만 읽고 저장소에 넣지 않습니다.
